# Metadata

- `expected_schema_*.json`: completar con los esquemas reales leídos de cada servicio.
- `canonical_schema_trips.json`: esquema lógico inicial basado en el caso; completar tipos y nulabilidad después de inspeccionar los archivos.
- `business_rules.json`: reglas iniciales del caso; confirmar con el ingeniero la diferencia entre rechazo y sospecha.

No inventar tipos, columnas o mapeos que no se hayan comprobado en los archivos reales.
