# Scripts auxiliares

Colocar aquí scripts pequeños de apoyo, por ejemplo:
- descarga controlada de archivos Parquet seleccionados;
- verificación de existencia y tamaño;
- generación de manifiesto de archivos;
- limpieza de resultados locales reproducibles.

Los scripts no deben sustituir a Spark como motor ETL ni transformar todo el dataset con Pandas.
No guardar archivos Parquet descargados dentro del repositorio Git.
